

# 🍔 DAW-2026 — Cardápio Digital

Este é um projeto em grupo da disciplina de Desenvolvimento de Aplicações Web (DAW). A ideia é criar um **cardápio digital para uma hamburgueria**, onde o cliente consegue ver os lanches, as opções e os preços de um jeito simples e bonito, direto pelo navegador.

## 💡 Sobre o projeto

Começamos montando o cardápio só com HTML e CSS, focando na estrutura da página e no visual. Depois que essa base ficou pronta, começamos a refazer o mesmo cardápio em React, para aprender como funciona a divisão em componentes e como deixar o código mais organizado e fácil de crescer.

Por isso, o repositório tem as duas versões lado a lado.

## 📁 O que tem em cada pasta

- **cardapio-html:** a primeira versão, feita só com HTML e CSS.
- **cardapio-react:** a versão em React, que começamos recentemente e ainda está em andamento.
- **assets:** imagens e outros arquivos usados nos projetos.

## 🛠️ Tecnologias

Na versão HTML usamos HTML5 e CSS3. Na versão React usamos React e JavaScript.

## 🚀 Como ver funcionando

A versão em HTML é bem simples: basta baixar o repositório, abrir a pasta `cardapio-html` e abrir o arquivo `index.html` no navegador.

Já a versão em React precisa do Node.js instalado. Depois é só entrar na pasta `cardapio-react`, instalar as dependências com `npm install` e rodar o projeto com `npm run dev`. O terminal vai mostrar o endereço para abrir no navegador.


## 🗺️ Status e próximos passos

A versão em HTML e CSS já está com a estrutura e o layout prontos. A versão em React está no começo, e o que queremos fazer a seguir é:

- Transformar as seções do cardápio em componentes React
- Organizar os itens do cardápio em uma lista de dados
- Publicar o projeto online com o GitHub Pages
